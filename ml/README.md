# AdaptiveQuiz AI — ML Student-Level Prediction Module

Machine-learning component that predicts a student's **initial learning level**
(Beginner / Intermediate / Advanced) before they start an adaptive quiz. The
predicted level seeds the quiz's starting difficulty; after the quiz begins,
the **existing** Elo + IRT + Adaptive Engine take over and adjust difficulty in
real time. **The ML model never replaces or overrides the adaptive engine.**

```
Student performance data
        │
        ▼
   ML Model (Random Forest)
        │
        ▼
   Initial Level (Beginner / Intermediate / Advanced)
        │
        ▼
   Adaptive Quiz starts at matching difficulty
        │
        ▼
   Student answers → Existing Elo → Existing IRT → Existing Adaptive Engine → Next question
        │
        └─────────────────────────────────────────────────────────────┘ (repeat)
```

## Dataset

`ml/dataset/student_performance_elo_dataset.csv` — one row per student attempt.

| Column | Description |
|---|---|
| `quiz_attempts` | Number of quiz attempts |
| `questions_attempted` | Total questions attempted |
| `correct_answers` | Total correct answers |
| `wrong_answers` | Total wrong answers |
| `accuracy` | Correct / attempted ratio |
| `avg_time_per_question` | Average seconds per question |
| `easy_correct` | Easy questions answered correctly |
| `medium_correct` | Medium questions answered correctly |
| `hard_correct` | Hard questions answered correctly |
| `previous_avg_score` | Average score in previous quizzes |
| `current_elo_rating` | Current Elo rating (0-based scale) |
| `question_difficulty_rating` | Elo difficulty of questions faced |
| `total_answered` | Cumulative total answered |
| `student_id` | **ID only — explicitly NOT an ML feature** |
| `student_level` | **Target variable** — Beginner / Intermediate / Advanced |

## ML algorithm

**Random Forest Classifier** (`sklearn.ensemble.RandomForestClassifier`):

```python
RandomForestClassifier(
    n_estimators=200,
    max_depth=12,
    random_state=42,
    class_weight="balanced"
)
```

## Model evaluation

**Stratified 5-Fold Cross-Validation** (`sklearn.model_selection.StratifiedKFold`):

```python
StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
```

Metrics (macro-averaged for the 3-class target): **Accuracy, Precision,
Recall, F1 Score** — reported per fold and averaged. All numbers come from the
actual trained model; nothing is hard-coded.

## Training

```bash
python ml/training/train_model.py
```

What it does:

1. Loads and validates the CSV (missing values, duplicate rows, column checks,
   class distribution, data types).
2. Separates `X` = 13 features, `y` = `student_level`.
3. Runs Stratified 5-Fold Cross-Validation, printing each fold's
   Accuracy / Precision / Recall / F1, then the averages.
4. Trains a final Random Forest on the **complete** dataset.
5. Saves the bundle to `ml/models/model.pkl` with `joblib`:

```python
{
    "model": <RandomForestClassifier>,
    "features": ["quiz_attempts", ..., "total_answered"]  # exact training order
}
```

The feature order inside `model.pkl` is what `predict.py` uses to reorder any
incoming data — prediction always sees columns in exactly the training order.

## Prediction

```bash
python ml/prediction/predict.py                 # built-in demo prediction
python ml/prediction/predict.py --json data.json  # predict from a JSON file
```

Or as a library (importable from Django):

```python
from ml.prediction.predict import predict_student_level

student = {
    "quiz_attempts": 2,
    "questions_attempted": 20,
    "correct_answers": 16,
    "wrong_answers": 4,
    "accuracy": 0.80,
    "avg_time_per_question": 35,
    "easy_correct": 7,
    "medium_correct": 6,
    "hard_correct": 3,
    "previous_avg_score": 75,
    "current_elo_rating": 350,
    "question_difficulty_rating": 200,
    "total_answered": 40,
}

result = predict_student_level(student)
# result == {
#     "predicted_level": "Intermediate",
#     "probabilities": {"Advanced": 0.167, "Beginner": 0.000, "Intermediate": 0.833},
# }
```

`predict.py` only **loads** the trained model and predicts — it never trains or
retrains. It returns the predicted level and per-class probabilities.

## How ML connects to the adaptive system

| Component | Responsibility |
|---|---|
| **ML model** (this module) | Predicts the **initial** level from historical/performance features |
| **Elo** (`study_core/services/adaptive_engine.py`) | Updates rating after each answer |
| **IRT** (`study_core/services/irt_engine.py`) | Estimates ability θ vs question difficulty b |
| **Adaptive Engine** (`study_core/services/adaptive_engine.py`) | Selects the next question targeting the optimal success rate |

The ML prediction seeds the starting difficulty only. Every subsequent question
is chosen by the existing Elo/IRT/adaptive engine based on live answers — the
predicted level is **not** a permanent lock.

## Error handling

`train_model.py` / `predict.py` raise clear, descriptive errors for:

- dataset file missing
- model file missing (with a "run train_model.py first" hint)
- required column/feature missing
- non-numeric / invalid input values
- corrupted `model.pkl` (wrong structure or unreadable file)
